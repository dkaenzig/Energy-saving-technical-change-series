# Energy-saving-technical-change-series

This repository hosts the quarterly input-saving technical change series as constructed in [Känzig Williamson (2025)](./K%C3%A4nzig%20Williamson%202025%20-%20ESTC.pdf).

The data can be found in: [input_saving_tech_series.csv](./input_saving_tech_series.csv)

The relevant information on the construction of the series is in the [paper](./K%C3%A4nzig%20Williamson%202025%20-%20ESTC.pdf).
